# Project Aegis mobile demo: 3 minutes

## Recording prep

- Open the app on a phone in portrait orientation using the computer's LAN URL. Keep both devices on the same trusted network.
- Before recording, tap the Operations sheet handle until the sheet is half-open and its tabs are visible. Do not swipe the sheet during setup; keep this position for the walkthrough.
- Load the app and any map or resource data you plan to show before recording. For the offline segment, disable the phone's network only after the app is loaded.
- Keep the phone number, exact location, and personal details out of frame. Do not send a real incident report or place a test call to 112.
- Use a known example location and describe nearby facilities as map listings, not confirmed services.

## Offline segment notes

Before recording, confirm that the app shell is loaded and decide whether to use browser network controls or airplane mode. If no real pending report is available, show the queue's empty or offline state instead of inventing a report. On reconnection, narrate that retry is available; only say a report synced if the app confirms it. Plain HTTP may limit phone geolocation and installable-app features.
